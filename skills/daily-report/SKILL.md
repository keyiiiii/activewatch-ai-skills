ActivityWatch API を使って、今日の作業日報を自動生成してください。

## 環境情報の取得

1. ActivityWatch API のベースURL: `http://localhost:5600/api/0/`
2. まず `buckets/` エンドポイントからバケット一覧を取得し、`aw-watcher-window` と `aw-watcher-afk` で始まるバケット名を動的に特定する
3. 現在時刻から今日の日付（JST: +09:00）を特定する

## データ取得

- ウィンドウアクティビティ: `buckets/<window-bucket>/events?start=<today>T00:00:00%2B09:00&end=<today>T23:59:59%2B09:00&limit=-1`
- AFK データ: `buckets/<afk-bucket>/events?start=<today>T00:00:00%2B09:00&end=<today>T23:59:59%2B09:00&limit=-1`

※ API の URL は末尾に `/` が必要な場合があるので注意

## 分析・出力

取得したデータを分析し、以下のフォーマットで日報を生成する:

```
## 日報 YYYY/MM/DD

### アクティブ時間
- 合計: X時間X分

### 作業サマリー
（アプリ名・ウィンドウタイトルから推測して、やったことを箇条書き。
職種を問わず、その人が実際に行った作業を正確に記述する。）
- 例: スプレッドシートで売上データの分析
- 例: FigJam で決済フローの仕様検討
- 例: PR レビュー・コードの修正
- 例: Zoom で定例ミーティング参加
- 例: Linear でスプリント計画

### アプリ別使用時間
| アプリ | 時間 |
|---|---|
| ... | ... |

### AI からの一言
（データから読み取れる傾向に基づいた軽いコメント。例: 「今日は分析作業に集中できた日ですね」「ミーティングが多めの日でした」「企画とコーディングを両立した日ですね」など）
```

## 注意
- loginwindow のデータは除外すること
- ウィンドウタイトルから作業内容を推測し、人間が読みやすい形にまとめること
- 使用時間が1分未満のアプリは省略してよい
- 特定の職種（エンジニア等）に偏った表現をしないこと。ユーザーの実際のアプリ利用パターンからその日の役割（開発、企画、分析、マネジメント等）を読み取り、それに合った表現を使う
- 日本語で出力すること
